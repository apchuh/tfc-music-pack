# TFC Music Pack

This resource pack replaces standard Minecraft music with music from the mod **TerraFirmaCraft**. It plays in the main menu, during gameplay, and everywhere else (Overworld, Nether, End, Creative, and Underwater).

## Tracks Included

- **Dreams Of The Phae** — Mike "Menoch" Pelaez (`dreams_of_the_phae.ogg`)
- **Firmavista** — Mike "Menoch" Pelaez (`firmavista.ogg`)
- **Sycamore Heights** — Mike "Menoch" Pelaez (`sycamore_heights.ogg`)
- **TerraFirmaCraft** — Mike "Menoch" Pelaez (`terrafirmacraft.ogg`)
- **Through The Willows** — Mike "Menoch" Pelaez (`through_the_willows.ogg`)

## Compatibility

- Minecraft: Java Edition `1.20.3–1.20.6`, `1.21.x`+

## Installation

1. Download the latest `.zip` from [Releases](../../releases) (or zip the repository root containing `pack.mcmeta`, `pack.png`, and `assets/`).
2. Place the `.zip` into your `.minecraft/resourcepacks` folder.
3. Enable **TFC Music Pack** in **Options → Resource Packs**.
